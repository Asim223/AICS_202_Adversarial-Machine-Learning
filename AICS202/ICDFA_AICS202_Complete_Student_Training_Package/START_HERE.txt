FIRST STEPS
- Read the first sections of the PDF manual.
- Extract the entire package into a writable student folder.
- Open a terminal in Labs and create a Python virtual environment.
- Install requirements.txt and launch Jupyter Notebook.
- Run notebooks sequentially, saving your own results and evidence.
- Complete the integrated 100-mark assessment when assigned in E-Campus.

SAFETY
Use only the supplied local dataset and learners' own local models.
Do not target public, production, or third-party systems without explicit written authorisation.

NOTE ON HOURS
